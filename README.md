# manuales-equipos-medicos 
# 📚 Repositorio de Manuales Técnicos de Equipos Médicos

Este repositorio contiene una colección organizada de manuales técnicos de equipos médicos, clasificados por **marca**. El objetivo es centralizar la documentación técnica y facilitar su acceso desde plataformas como **Notion** mediante enlaces directos.
